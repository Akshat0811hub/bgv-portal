# bgv-portal (Orbit Verify)

Enterprise Background Verification & Screening Portal with Multi-Tenant Client and Master Admin Management.

## Features
- **Master Admin Portal**: Full operational management, case creation, real-time MIS reports, team management, and audit logging.
- **Client Organization Portal**: Multi-tenant client dashboard, secure case submission, live TAT tracking, and PDF report downloads.
- **Candidate Self-Upload Flow**: Secure tokenized upload interface with drag-and-drop, validation, and real-time status updates.
- **Automated Verification Pipeline**: Address, Education, Employment, Criminal & Identity verification workflows.
- **Modern UI/UX**: Sleek, glassmorphic styling, responsive layout, and mobile-friendly design.
